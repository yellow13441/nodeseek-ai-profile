# NodeSeek 发布帖归档

这里保存每个正式版本可直接发布到 NodeSeek 论坛的 Markdown 帖子。

## 更新约定

- 普通开发、修 Bug 或尚未决定公开发布时，不要求修改发布帖。
- 当维护者明确决定把某个版本推送到 GitHub，并同步发布到 Greasy Fork 时：
  1. 新增或更新 `NODESEEK_RELEASE_POST_vX.Y.Z.md`。
  2. 标题、版本号、安装链接、功能、截图和已验证结果必须与实际发布版本一致。
  3. 不把未测试能力写成“测试通过”，不使用尚未对外发布的链接。
  4. 发布帖应与该版本的脚本、README 和 CHANGELOG 一起提交到 GitHub。
- 发布后的普通代码修改可以暂时不动发布帖；只有下一次明确发版时再生成对应版本的新文件。
- 图片优先使用已经确认可公开访问的图床链接；不得把 Auth-Token、API Key 或删除凭据写入文档。
